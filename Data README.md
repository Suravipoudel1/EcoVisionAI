# Data Sources

This directory documents the datasets and satellite imagery used in EcoVision AI.

## 1. Brick Kiln Dataset

**Dataset:** GEO-Bench m-brick-kiln

**Source:** https://huggingface.co/datasets/recursix/geo-bench-1.0

Used for training, validation, and testing the brick kiln classification model.

## 2. Kathmandu Valley Reference Data

The external evaluation used 108 kiln locations and 108 non-kiln reference points.

The reference data are not included in this directory.

## 3. Satellite Imagery

- Source: Sentinel-2 Surface Reflectance Harmonized
- Platform: Google Earth Engine
- Study area: Kathmandu Valley, Nepal
- Period: December 1, 2025 – May 1, 2026

## 4. Data Availability

Raw datasets and satellite imagery are not included here. Refer to the research notebook for data access and preprocessing details.

Third-party data remain subject to their original access terms and licenses.
